# AutoLux Pro - Nova aplicação

Esta pasta contém uma nova aplicação React/Vite criada a partir da ideia do projeto AutoLux original, sem substituir os ficheiros da aplicação inicial.

## Melhorias incluídas

- Interface visual renovada e responsiva.
- Catálogo com pesquisa por marca, modelo, cor ou etiqueta.
- Filtros por marca, combustível, caixa e preço máximo.
- Ordenação por destaque, preço, ano e quilometragem.
- Favoritos persistentes com `localStorage`.
- Comparador de até 3 viaturas.
- Formulário de contacto com validação e seleção automática da viatura.
- Dados organizados em módulo JavaScript e componentes reutilizáveis.

## Como correr

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

Depois da build pode testar com:

```bash
npm run preview
```
